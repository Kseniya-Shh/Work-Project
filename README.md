# Work-Project

Выделение функциональных требований безопасности и нефункциональных требований безопасности для проекта, связанного с разработкой умного дома (с использованием умных устройств: лампочки, колонки, датчики, чайники, камеры и т.п.). Оформление User Story для этих требований, а так же составление примерной дорожной карты разработки.
